# 微信语音输入远程状态监听板

开发者：Althy、DRHW。模块版本：1.0.5。

兼容向日葵中英文客户端（AweSun / SunloginClient），不依赖远端电脑名称、窗口标题或安装目录。改名客户端通过文件原始名称或厂商／产品／远程控制描述联合识别；排除服务、守护程序和更新器。元数据查询有缓存和定期刷新，读取失败时不抢占未知应用焦点。

在工具箱打开开关即可常驻运行，同时启用开机自启动；关闭会停止程序并取消自启动。微信语音开启后开始监听：进入向日葵时激活本机承接板，切到其他应用时隐藏，返回向日葵时再次承接。文字变化立即复制，保留换行；语音结束立即收尾，不增加等待时间。收尾后迟到的文字回调仍可复制。

不拦截快捷键，不模拟输入，不操作远端电脑，不联网。仅在本机记录状态和字符数量，不记录正文。剪贴板被其他应用占用时保留文字并重试；最终失败可通过托盘菜单重试。

需要 Windows、.NET Framework 4、微信输入法和向日葵。使用 `scripts/build-helpers.ps1` 构建。焦点转移受 Windows 权限限制；本程序不会自动提升权限或无限重试。

回归测试将剪贴板输出替换为内存接收器，运行真实文字回调、复制和收尾代码，不接触用户剪贴板或焦点。测试覆盖迟到提交、换行保留、同步复制、空输入收尾、隐藏时保留文字、占用重试、嵌套提交和焦点策略。它不能替代不同微信输入法版本的实机兼容性验证；当前主要流程已由用户实测成功。

首次启用时，工具箱自动从随版本发布的源码构建并安装程序，无须手动运行构建脚本或复制 EXE。构建只使用 Windows .NET Framework 编译器和本模块固定源码／图标；失败时不写入启动项。
