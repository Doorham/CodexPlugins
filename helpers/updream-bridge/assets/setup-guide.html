只需在浏览器做一次复制，再回到工具箱验证保存。

1登录 UpDream，进入任意画布

按 F12 打开浏览器开发者工具，点击 Console（控制台）。这是同一个标签的英文和中文名称。

2若控制台阻止粘贴，先解除限制

看到浏览器的安全提示时，按提示手动输入允许粘贴的文字并回车；没有提示就直接下一步。

英文提示常见 allow pasting；中文界面可能显示“允许粘贴”。以当前浏览器实际提示为准。

3复制 F12 代码，粘贴到 Console

回到 UpdreamBridge 配置窗口，点击按钮，再回 Console 粘贴并按回车。代码会把必要字段复制到剪贴板。

4把返回内容粘贴回配置窗口

Console 执行后，回到工具箱的登录信息输入框，直接粘贴剪贴板里的 JSON。

登录信息输入框：粘贴 JSON→验证并保存

使用前，这台电脑必须登录 UpDream；目前不支持多端。若被其他设备顶号，当前连接会失效，请在本机重新登录并配置。登录 JSON 含令牌，只粘贴到本机配置窗口。
