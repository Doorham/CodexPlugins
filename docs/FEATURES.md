# 全部功能说明

## 1. Codex 对话 timeout 修复

### 解决什么

当 Codex 新对话或久置对话的 Responses WebSocket 没有从第一次连接开始遵循 Windows 系统代理时，可能先出现多次固定超时，最后才回退到其他传输方式。该功能幂等确保 Codex 启用 `respect_system_proxy`。

### 怎么用

- **配置系统代理**：仅在 `respect_system_proxy` 缺失或关闭时出现；修正 `%USERPROFILE%\.codex\config.toml`，修改前在本机私人目录建立备份。
- **已配置**：配置存在时显示为不可点击状态，不会重复写入配置，也不表示正在重连 Codex。
- **检测连接**：调用 Codex 自带诊断能力，只提取 WebSocket 状态、握手结果和耗时。

### 安全边界

- 不关闭、切换或配置 VPN。
- 不读取代理节点、订阅、账号、Token 或对话正文。
- 配置文件不合法时会停止，不会覆盖损坏的 TOML。
- 该功能不保证解决所有网络问题；HTTP 101 只证明本次 WebSocket 握手成功。检测失败时应继续排查代理线路、本地网络或服务端，而不是重复配置。

## 2. 国内网站直连

### 解决什么

当 Windows 系统代理开启时，指定的国内站点可以直连，避免不必要的绕路和高延迟。功能同时维护 Windows `ProxyOverride`，并在检测到 Clash Verge Rev 时幂等维护其系统代理绕过项。

### 怎么用

- **管理白名单**：输入主域名，例如 `example.com`。系统同时处理主域名和子域名覆盖。
- **删除**：只能删除工具箱记录为自定义的项目，不会删除内置规则或用户原有规则。
- **刷新网络**：重新同步工具箱拥有的绕过项，并通知 Windows 刷新系统代理状态。

输入规则：

- 只输入域名，不要输入账号、口令、Token 或完整带查询参数的私人 URL。
- 已有父域覆盖时，不会重复写入子域规则。
- 自定义规则只保存在当前电脑，不上传 GitHub。

### 安全边界

- 只处理 Clash Verge Rev 顶层的系统代理绕过设置。
- 不读取、记录或修改订阅、节点、策略组、控制密钥、模式和端口。
- 修改 Clash Verge Rev 绕过设置前会建立本地备份。

## 3. Updream 剪贴板清理

### 解决什么

从 Updream 画布复制图片时，剪贴板可能同时包含画布结构数据和图片。该助手在确认数据符合 Updream 画布格式时，保留原始 PNG，并补充常用 Windows 图像剪贴板表示，提高向 Codex 等应用粘贴的兼容性。

### 不会做什么

- 不保存、上传、压缩、缩放或重新编码原始 PNG。
- 不处理普通文字、普通 JSON、普通图片、文件拖放或无效 PNG。
- 不保存剪贴板历史。

### 使用

点击“点我开启”后即可在后台工作；点击“点我停用”会停止助手并取消开机自启。

## 4. Codex 完成提示音

### 解决什么

在 Codex 完成一次回答时播放提示音，方便用户在后台等待任务时及时返回。

### 怎么用

- **点我开启 / 停用**：启动或停止后台监听器，并同步当前用户自启。
- **测试声音**：立即播放当前选择的声音；可连续测试。
- **选择声音**：支持 WAV、MP3 和 WMA。选择后会把音频复制到当前用户的本地安装目录，避免原文件被移动后失效。
- 未选择声音或自定义声音播放失败时，回退到 Windows 系统提示音。

### 隐私边界

- 只根据完成事件元数据决定何时播放。
- 不保存、输出或上传对话正文。
- 自定义音频只保存在当前电脑，不进入 Git。

## 5. Arctis Nova 5 电量监控

### 解决什么

当检测到 Arctis Nova 5 USB 接收器时，显示托盘电量图标并查询耳机电量。接收器不存在时，工具箱会隐藏该卡片，启动门卫也不会拉起监控器。

### 状态区分

- **接收器不存在**：卡片隐藏，监控器不运行。
- **接收器存在，耳机关机/未联机**：卡片保留，状态显示离线。
- **耳机在线**：托盘图标显示电量数字，低电量使用更明显的颜色。

### 安全边界

- 网络版只包含可维护的 C# 源码，不包含原始用户归档或外部二进制包。
- 只执行电量查询和本地托盘显示，不包含固件更新、配对或设置写入功能。

## 6. 软件安装检查

### 解决什么

判断当前 Windows 电脑是否达到最低开发条件，而不是只看“软件名字是否出现在安装列表”。检查分为开发工具、Python 基础开发环境、编辑器集成三层，并对 VS Code、Visual Studio、Cursor 和 PyCharm 提供明确的已验证路线。

### 检查边界

- Python 会验证版本、实际执行和短路径临时虚拟环境，而不是只检查 `python.exe` 是否存在。
- 编辑器集成会验证对应的 Python 扩展、工作负载或解释器路线；编辑器和 Python 分别安装并不自动等于集成合格。
- 大型编辑器、Python、Visual Studio 工作负载和编辑器扩展只提示，不自动下载或安装。
- 临时验证目录位于 `%TEMP%\EDV`，检测完成后清理。

## 7. Codex 环境补全

### 解决什么

检查 PowerShell 7、Windows Terminal、UTF-8、Git、FFmpeg/FFprobe、PyYAML 和 yt-dlp，并在用户确认后处理能够安全、确定补全的缺项。全部合格时按钮显示“已配置齐全”，不会执行无意义操作。

### 安全边界

- Git 和 FFmpeg 会以临时仓库、临时媒体验证真实能力，随后清理。
- UTF-8 修改前保存 ACP、OEMCP 和 MACCP；任一步失败会回滚，恢复原编码也会先建立安全快照。
- UTF-8 修改或恢复需要管理员确认，并在完成后明确提示重启 Windows。
- 复杂的 Python、PATH、权限、代理或企业策略异常不会被强行改写，而是保留错误详情供进一步判断。
- 不检测、不替换、不注册也不修复 DirectX、系统 DLL、Visual C++ 系统组件或 API Sets。

两个开发环境模块共用一个 `EnvironmentDetector.exe`。同一时间只允许一个窗口实例，再次点击任一卡片会复用现有窗口并切换到对应页面。环境补全运行期间切页只读取缓存结果，补全任务继续使用启动时的独立快照，不会被取消、重启或改写。

## 网络版明确不包含的功能

- 不包含任何网络驱动器映射、公司共享路径或内网端点管理功能。
- 不包含 Logitech G435 电量监控，因为该功能依赖不随网络版发布的外部 DLL。
- 不包含任何代理节点、订阅、凭据、私人白名单或私人插件数据。
