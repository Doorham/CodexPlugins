# 公司模块接入（现行基线）

公共工具箱默认不启用两个公司模块，没有公司码或公司设置入口，也不包含公司的网段、NAS 地址或 Tailscale 节点信息。原有八个公共模块保持原功能。仅公司 NAS 连接与公司四盘访问依赖公司文件；硬件模块仍按设备是否存在显示。

公司通过内部渠道保存并交付一个 JSON 引导文件。新电脑取得一份本地副本即可导入，无须连接原始存储盘，不依赖 GitHub 私有仓库、镜像或公司验证服务器。真实公司文件仅保存在指定内部目录，不随源码、共享索引、公共包分发。

使用工具箱配套 Python 执行 `apps/plugin-station/agent_cli.py import-company-guide <收到的文件路径>`。文件格式为 `codextools-company-guide/v1`；只接受固定 companyId、两个模块 ID、W/X/Y/Z UNC 目标、默认用户名和说明文本。不接受密码、令牌、脚本、下载地址或自定义命令。说明文本只供阅读，不执行。固定处理器编译工具箱自带的通用连接程序，复制数据到当前 Windows 用户本机状态目录，并用 DPAPI 封装文件哈希记录。导入不安装 Tailscale、不登录、不创建盘符；源码缺失或编译失败时保留原本机有效记录。

导入后两个公司模块显示。用户点击连接才检查或安装 Windows Tailscale；安装器从固定官方源下载并核验固定 SHA256，不再分发第三方安装器。已有 Tailscale 与授权复用；需要授权时打开官方登录页面选择 GitHub。随后显式分别确认两台 NAS 账号和密码，全部确认后再预检盘符并映射。已有不同目标时停止，不覆盖或断开；密码不落盘，不进入引导文件、日志或源码。公司网络盘修复不能跳过凭据流程建立映射。旧私人 NAS 入口停用且禁止共享。

本机记录校验失败或缺失时，公司 UI、后台与 Agent 都拒绝动作。直接运行连接程序也检查记录、目录和自身/配置哈希。公司连接仍必须由用户完成交互凭据，Agent 不提供无交互连接动作。源码更新与重启不覆盖本机状态。

引导文件含内部网络信息，应作为公司内部文件保存和传递。它提供配置，并不证明员工身份；访问权限由 Tailscale 和 NAS 控制。DPAPI 本机记录不阻止有权修改自身程序的用户。此方案降低公共分发泄露风险，不构成对公司账户策略或合规情况的整体审计结论。

本版支持从收到的本地引导文件启用模块，不依赖公司盘符或公司服务器。公开仓库只发布通用源码，不发布引导文件、NAS 目标、Tailscale 节点信息、安装器二进制或本机状态。新电脑首次安装、授权与真实外网映射尚需实际验证。
