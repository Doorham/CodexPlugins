# CodexTools Online 开发日志

## 长期规则

- 使用三段式语义化版本，`main` 始终可启动。
- 更新器只从当前克隆的 GitHub `origin/main` 快进更新。
- 仓库不保存凭据、对话、日志、诊断库、内网拓扑、私人状态或未经独立审计的外部二进制。
- 更新不强制覆盖本地改动，不自动合并分叉历史。
