# CodexTools Online 开发日志

## 长期规则

- 使用三段式语义化版本，`main` 始终可启动。
- 更新器只从当前克隆的 GitHub `origin/main` 快进更新。
- 仓库不保存凭据、对话、日志、诊断库、内网拓扑、私人状态或未经独立审计的外部二进制。
- 更新不强制覆盖本地改动，不自动合并分叉历史。

## 变更记录

### 2026-08-28 · v0.11.6 · Windows PowerShell 5.1 中文编码兼容 · Althy

- 全部 PowerShell 脚本统一为 UTF-8 with BOM 与 CRLF，避免中文 Windows 上的 Windows PowerShell 5.1 按 ANSI 代码页误读脚本文字。
- 桌面快捷方式安装、私人插件生成和开发启动脚本不再因中文路径、标签或提示文字发生乱码及 `.lnk` 后缀损坏。
- 两个 Python 启动期维护脚本改用 ASCII JSON 跨越原生进程边界，再由 PowerShell 解析并显示中文，避免 Python UTF-8 输出被 PowerShell 5.1 按本地代码页误解。
- 新增全仓 BOM 编码守卫，并由 `.gitattributes` 仅统一 PowerShell 脚本的 CRLF；不使用存在客户端兼容风险的 `working-tree-encoding`。
- 验证完成：Windows PowerShell 5.1 成功解析全部 11 个脚本；完整 `unittest` 共 64 项及 `git diff --check` 全部通过。
- 未解决项：无。

### 2026-08-28 · v0.11.5 · 后台常驻助手自动恢复 · Althy

- 为 `process_app` 增加显式 `keepAlive` 生命周期策略；只有已开启自启的常驻模块在进程意外消失后，才会由工具箱启动及五秒状态刷新自动恢复。
- Codex 完成提示音与 Updream 剪贴板清理同步升级至 `1.0.3`；按需环境工具、已停用插件和硬件门控模块不会被误启动。
- 十分钟最多自动恢复三次，仍不稳定时暂停重试并显示原因；异常卡片同时提供“恢复运行”和“关闭自启”，避免无限重启或第一次点击误停用。
- 验证完成：助手构建成功；完整 `unittest` 共 61 项及 `git diff --check` 全部通过，并继续覆盖 GitHub 单一更新源、无内部端点、无内部模块和无 EXE/DLL 载荷边界。
- 未解决项：工具箱自身完全退出期间不承担中途守护；后台助手仍会在下次登录或工具箱再次启动时恢复。

### 2026-08-26 · v0.11.4 · 修复新版 Codex 完成事件漏响 · Althy

- Codex 完成提示音升级至 `1.0.2`，改用每个任务只产生一次的 `task_complete` 元数据作为响铃信号。
- 不再依赖新版 Codex 已停止写入的直接 `agent_message/final_answer` 事件，避免监听器进程仍在但实际完成后不响。
- 明确忽略同一回答对应的 `response_item` 和 `item_completed` 包装事件，防止一个任务播放两次；无论 Codex 是否位于前台都继续响铃。
- 新增不读取回答正文的事件格式自检与回归测试；公开仓库仍不携带用户自定义声音或预编译二进制。
- 验证完成：助手构建成功；事件格式自检通过；完整 `unittest` 共 54 项全部通过；公开发布边界检查和 `git diff --check` 通过。
- 发布边界仍确认无预编译 EXE/DLL、公司内网路径、内部交接资料、私人声音、日志或本机状态。
- 未解决项：仓库不提供预编译 EXE，使用者仍需在自己的 Windows 电脑上从源码构建；本次不宣称任何可信代码签名。
