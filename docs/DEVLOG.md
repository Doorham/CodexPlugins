# CodexTools Online 开发日志

## 长期规则

- 使用三段式语义化版本，`main` 始终可启动。
- 更新器只从当前克隆的 GitHub `origin/main` 快进更新。
- 仓库不保存凭据、对话、日志、诊断库、内网拓扑、私人状态或未经独立审计的外部二进制。
- 更新不强制覆盖本地改动，不自动合并分叉历史。

## 变更记录

### 2026-08-26 · v0.11.4 · 修复新版 Codex 完成事件漏响 · Althy

- Codex 完成提示音升级至 `1.0.2`，改用每个任务只产生一次的 `task_complete` 元数据作为响铃信号。
- 不再依赖新版 Codex 已停止写入的直接 `agent_message/final_answer` 事件，避免监听器进程仍在但实际完成后不响。
- 明确忽略同一回答对应的 `response_item` 和 `item_completed` 包装事件，防止一个任务播放两次；无论 Codex 是否位于前台都继续响铃。
- 新增不读取回答正文的事件格式自检与回归测试；公开仓库仍不携带用户自定义声音或预编译二进制。
- 验证完成：助手构建成功；事件格式自检通过；完整 `unittest` 共 54 项全部通过；公开发布边界检查和 `git diff --check` 通过。
- 发布边界仍确认无预编译 EXE/DLL、公司内网路径、内部交接资料、私人声音、日志或本机状态。
- 未解决项：仓库不提供预编译 EXE，使用者仍需在自己的 Windows 电脑上从源码构建；本次不宣称任何可信代码签名。

### 2026-08-26 · v0.11.3 · 环境任务可视化与运行期窗口保护 · Althy

- “软件安装检查”和“Codex 环境补全”同步升级至 `1.1.0`；检测、重新检测及自动补全过程显示彩色月相循环动画、真实处理项目、步骤位置与已用时间。
- 新增不安装软件、不修改注册表、不请求提权的预览模式，用于安全验收安装中的动画、提示和窗口保护。
- 补全或 UTF-8 恢复运行时，禁止在两个环境页面间切换并拦截关闭请求；最小化、切换其他应用和 Windows 关机仍保持可用。
- 月相图采用 Microsoft Fluent Emoji 官方 3D PNG，使用预乘 Alpha 消除浅色边缘；MIT 许可说明随源码提供并安装到助手目录。
- 发布前验证：助手构建成功；完整 `unittest`、公开仓库边界检查和 `git diff --check` 全部通过。
- 未解决项：仓库不提供预编译 EXE，使用者仍需在自己的 Windows 电脑上从源码构建；本次不宣称任何可信代码签名。

### 2026-08-25 · v0.11.2 · timeout 模块区分配置与连接状态 · Althy

- `codex-system-proxy` 升级至 `1.1.0`；只有系统代理功能未配置时才显示配置动作。
- 已配置时显示不可点击的“已配置”，旁边只保留独立的“检测连接”，避免用户反复点击并误以为该动作会重连 Codex。
- HTTP 101 只证明当前 WebSocket 握手成功；检测失败明确提示继续排查代理线路或网络，不再宣称所有 timeout 已被修复。
- 新增状态动作、失败文案和禁用按钮回归检查，并继续执行公开仓库安全边界测试。
